## Getting Started

You can run the project locally to explore its implementation or make your own improvements.

### Prerequisites

- Node.js
- npm
- A Supabase project for authentication and cloud-backed features

### Installation

Clone the repository:

```bash
git clone https://github.com/Likitha3126/learn-ai-with-me.git
cd learn-ai-with-me
```

Install dependencies:

```bash
npm install
```

### Environment Variables

Create a `.env` file in the project root and configure your Supabase credentials:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key
```

Replace the example values with your own Supabase project URL and publishable key. Never commit your `.env` file or secret credentials to GitHub.

### Run the Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
